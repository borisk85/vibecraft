## СПРАВКА (перенесено из memory 2026-07-18)

**Услуги и деньги:** 6 направлений (боты, AI-агенты, MVP веб, AI-сайты, автоматизации, MVP мобильных). Все цены «от», минимальный чек 150 000 ₸, точный расчет — кастомный PDF после ТЗ. Оплата 50/50 (предоплата / после демо), 14 дней бесплатных правок (баги и мелочи по ТЗ, не фичи), на ЕСП/ИП. Поддержка: «По часу» 25k/ч, «Базовый» 90k/мес (до 5ч), «Расширенный» 240k/мес (до 15ч); новые фичи = отдельный проект. Скидка повторным −10-15% (внутреннее, не афишировать). GEO и Speed Boost — услуги ВНУТРИ vibecraft, не отдельный бренд/домен, цены не подтверждены.

**Сроки (подтверждены, не выдумывать):** вся линейка макс 1-2 недели; бот до недели; MVP веб/мобилка до 2 недель.

**MVP-границы:** рабочий прототип одной фичи (авторизация + БД + деплой + минимальный UI), НЕ готовый SaaS. Не входит: админка/дашборды, тарифы/роли, локализация, CRM-интеграции, полная полировка. Мобильный — Flutter, сборка APK/TestFlight; без сторов, push, IAP.

**Инфра/лиды:** DNS только через Cloudflare (ps.kz — регистратор, не авторитетен). Client email — Resend (noreply@vibecraft.kz). Лиды форм и калькулятора падают в Telegram @vibecraft_leads_bot (CHAT_ID 661638470), email-дубль не нужен. Аналитика YM/GA ID — пусто.

**Не поломать (код):** services (Services.tsx) и faqs (FAQ.tsx) — именованные экспорты, single source для UI + JSON-LD. Логотип — lib/logo-path.ts (V_PATH). PDF-смета: логотип через Svg+Path (не Image), Inter по HTTP, кириллица .normalize("NFC") — иначе tofu.

**Отложено (docs/backlog.md — единый источник):** Cases → /cases при 3+ кейсах; GitHub org @vibecraft при первом платном клиенте.

**Маркетинг (docs/marketing-plan.md):** порядок каналов — партнерства с агентствами (аутрич через скрейпинг позже). Ads/IG/YouTube пока не предлагать.
