# /find-affiliates

Ищет прямые партнерские программы компаний (регистрация на сайте компании, НЕ через сети Impact/CJ/FlexOffers/Awin) под тему конкретного сайта. Все сети для КЗ закрыты (июнь 2026) — прямые программы единственный аффилиат-канал до переподачи в сети.

## Usage
`/find-affiliates [keyword или site-name]` — полный поиск (live-сайт)
`/find-affiliates [keyword] --quick` — быстрый прогноз (вызывается из /final-audit)

## Фильтр выплат для Казахстана — ЖЕСТКИЙ, проверять ПЕРВЫМ

✅ Подходит: wire/SWIFT на банк (Kaspi принимает USD, SWIFT CASPKZKAXXX), крипто (USDT), Wise-получение НЕ работает.
⛔ Отсев: только Payoneer (аккаунт Boris закрыт навсегда), только PayPal (в КЗ не выводится), Stripe, бумажный чек, только US bank/ACH.
⛔ Программа живет внутри сети (Impact/CJ/ShareASale/Awin/FlexOffers/PartnerStack/Rakuten) → это НЕ прямая. Пометить «через сеть — после переподачи (сентябрь 2026+)», в текущий список не включать.
✅ Признаки прямой программы: своя платформа или Tapfiliate / FirstPromoter / Rewardful / Post Affiliate Pro / LeadDyno / Tolt / own dashboard. ВАЖНО: платит компания, не платформа — способ выплаты проверять у компании (страница FAQ/Terms партнерки, при неясности — готовить вопрос в поддержку).

## What it does — режим --quick (для /final-audit, ≤5 минут)

1. WebSearch `"[keyword/ниша]" affiliate program` + `[категория продукта] partner program`.
2. Оценить: есть ли в нише 2+ прямых программы с комиссией $10+ и выплатой не-Payoneer/не-PayPal-only.
3. Вернуть одну строку для прогноза дохода аудита: «прямые партнерки: ЕСТЬ (примеры) / НЕТ — только реклама».

## What it does — полный режим (live-сайт)

1. Read `C:/Claude Code/niche-tools/IDEAS_TRACKER.md` + `sites/[site]/COMPETITOR_ANALYSIS.md` (если есть) — понять нишу, аудиторию, какие продукты/сервисы ей нужны.

2. Собрать кандидатов (10-20 компаний), WebSearch:
   - `[ниша] affiliate program`, `[ниша] referral program`
   - `best [ниша] affiliate programs direct in-house`
   - продукты, которые логично рекомендовать аудитории сайта (SaaS, сервисы, инструменты — НЕ дешевые физические товары)

3. Для каждого кандидата WebFetch страницы партнерки (НЕ верить подборкам-блогам — только первоисточник):
   - Прямая или через сеть? (см. фильтр выше)
   - Комиссия и модель (% / фикс за лид / recurring)
   - Cookie, минималка выплаты, способы выплаты, гео-ограничения для паблишеров
   - Требования к сайту/трафику (многие прямые берут без минимума)

4. Прогнать фильтр выплат для КЗ. Способ выплаты не указан → статус «уточнить», подготовить 2-строчный вопрос в поддержку на английском (Boris отправит или агент через форму).

5. Сохранить `sites/[site]/DIRECT_AFFILIATES.md`:
   `| Компания | Комиссия | Cookie | Выплата | Мин. порог | Статус (✅ подать / ❓ уточнить / ⛔ отсев+причина) | Ссылка на заявку |`

6. Отчет Boris (3 блока, простой язык): сколько проверено / топ-3 подходящих с цифрами комиссий / одно действие (подать заявку на лучшую — заявки подает Boris, тексты заявки готовит агент).

7. Найдено 0 подходящих → сказать честно «в этой нише прямых программ с выплатой в КЗ нет, сайт остается на рекламе». НЕ натягивать слабые варианты.

## Когда вызывается
- Из `/final-audit` (--quick) — прогноз аффилиат-потенциала ДО постройки сайта.
- Из `/monitor-sites` — когда live-сайт вышел из песочницы / появился трафик.
- Вручную — для любого live-сайта.

## Notes
- Перед запуском перечитать memory `kz-payout-channel.md` — статусы сетей и каналов выплат меняются.
- Найденную программу «через сеть» не выбрасывать насовсем — записать в DIRECT_AFFILIATES.md с пометкой «после переподачи в сети».
- Заявки в прямые программы тоже могут отказывать новым сайтам — подавать когда есть хоть какой-то трафик, не в день запуска.
